# Lab 09: Advanced Embedded Platforms (Raspberry Pi & ESP32)

## 🎯 Objective
Introduce students to platforms beyond Arduino:
- Raspberry Pi (Single Board Computer)
- ESP32 (WiFi-enabled Microcontroller)

---

## 🧠 Concepts Covered
- Microcontroller vs Single Board Computer
- Python vs Arduino programming
- WiFi-enabled embedded systems

---

## 🥇 Raspberry Pi
- Runs Linux OS
- Uses Python for GPIO control
- No upload required (run code directly)

---

## 🥈 ESP32
- Microcontroller with built-in WiFi
- Programmed using Arduino IDE
- Supports IoT applications

---

## 📈 Learning Outcome
Students will understand:
- Differences between Arduino, ESP32, Raspberry Pi
- How embedded systems scale in complexity

---

## ⚠️ Note
This is a demonstration-based lab.
Students are not required to implement individually.
