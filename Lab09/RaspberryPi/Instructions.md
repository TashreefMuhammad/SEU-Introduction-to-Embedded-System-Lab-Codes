# Raspberry Pi Instructions

## 🧠 Key Idea
Raspberry Pi is a **full computer**, not just a microcontroller.

👉 No upload is required like Arduino.  
👉 Code runs directly using Python.

---

## 🔧 Requirements
- Raspberry Pi with OS installed
- LED + resistor

---

## 🔌 Wiring
- GPIO 18 (Physical Pin 12) → LED (with resistor)
- GND → GND

---

## ▶️ Steps to Run

### 1. Open Terminal

### 2. Navigate to file location
```bash
cd Desktop
```

### 3. Run the Python script
```bash
python3 led_blink.py
```

### ⛔ Stop Program
```bash
Ctrl + C
```
