# Lab 03: Digital Input Handling

## 🎯 Objective
Read external inputs and act accordingly.

## 🧠 Concepts Covered
- Digital Input
- Conditional Logic

## 🔧 Components Required
- Arduino Uno
- Push Buttons
- LEDs

## 🔌 Pin Configuration
- Inputs → Pins 7, 8
- Outputs → Pins 10, 11

## 📜 Description
Button inputs control LED behavior.

## ▶️ How to Run
Press buttons to change LED state.

## 🧪 Practice Task (In-Lab)
- Add more input combinations
- Create custom logic patterns

## 📈 Expected Learning Outcome
Students understand how to interact with external inputs.
