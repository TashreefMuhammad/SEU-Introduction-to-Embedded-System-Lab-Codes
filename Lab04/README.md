# Lab 04: Sensor Introduction (PIR / Ultrasonic / DHT11)

## 🎯 Objective
Introduce basic sensors and data acquisition.

## 🧠 Concepts Covered
- Sensor interfacing
- Analog/Digital data reading

## 🔧 Components Required
- PIR Sensor (HC-SR501)
- Ultrasonic Sensor (HC-SR04)
- DHT11 Sensor

## 🔌 Pin Configuration
(Depends on setup)

## 📜 Description
This lab introduces multiple sensors and how to read their values.

## ▶️ How to Run
Upload code and observe values in Serial Monitor.

## 🧪 Practice Task (In-Lab)
- Modify threshold conditions
- Trigger actions based on sensor data

## 📈 Expected Learning Outcome
Students learn how sensors interact with microcontrollers.
