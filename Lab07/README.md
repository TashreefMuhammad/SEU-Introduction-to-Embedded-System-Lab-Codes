# Lab 07: Servo Control using Ultrasonic Sensor

## 🎯 Objective
Control actuator based on sensor data.

## 🧠 Concepts Covered
- Mapping values
- Servo control

## 🔧 Components Required
- Ultrasonic Sensor
- Servo Motor

## 🔌 Pin Configuration
- Servo → Pin 6
- TRIG → Pin 9
- ECHO → Pin 10

## 📜 Description
Distance is mapped to servo angle.

## ▶️ How to Run
Upload code and observe servo movement.

## 🧪 Grading Task (In-Lab)
- As instructed in class

## 📈 Expected Learning Outcome
Students understand sensor-to-actuator mapping.
