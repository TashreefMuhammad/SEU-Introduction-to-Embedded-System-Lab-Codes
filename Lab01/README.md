# Lab 01: LED Blink

## 🎯 Objective
Understand basic digital output using Arduino.

## 🧠 Concepts Covered
- Digital Output
- Delay Function

## 🔧 Components Required
- Arduino Uno
- LED
- Resistor (220Ω)

## 🔌 Pin Configuration
- LED → Pin 10

## 📜 Description
This program blinks an LED at a fixed interval.

## ▶️ How to Run
Upload the code and observe the LED blinking.

## 🧪 Practice Task (In-Lab)
- Change blinking speed
- Add multiple LEDs

## 📈 Expected Learning Outcome
Students understand how to control digital outputs.
