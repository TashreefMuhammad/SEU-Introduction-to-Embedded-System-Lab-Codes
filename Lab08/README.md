# Lab 08: Smart Alarm System

## 🎯 Objective
Build a simple embedded system.

## 🧠 Concepts Covered
- State logic
- Multi-output control

## 🔧 Components Required
- PIR Sensor
- LED
- Buzzer

## 🔌 Pin Configuration
- PIR → Pin 7
- LED → Pin 11
- Buzzer → Pin 5

## 📜 Description
System detects motion and activates LED + buzzer.

## ▶️ How to Run
Upload code and observe system response.

## 🧪 Grading Task (In-Lab)
- As instructed in class

## 📈 Expected Learning Outcome
Students learn system-level design and integration.
