# Lab 02: Serial Control of LED

## 🎯 Objective
Control hardware using Serial Monitor input.

## 🧠 Concepts Covered
- UART Communication
- Serial Input Processing

## 🔧 Components Required
- Arduino Uno
- LED

## 🔌 Pin Configuration
- LED → Pin 10 / 11

## 📜 Description
Users send commands via Serial Monitor to control LEDs.

## ▶️ How to Run
Open Serial Monitor → send inputs (1, 2, 3...)

## 🧪 Practice Task (In-Lab)
- Add new commands
- Control brightness or patterns

## 📈 Expected Learning Outcome
Students learn basic communication between PC and MCU.
