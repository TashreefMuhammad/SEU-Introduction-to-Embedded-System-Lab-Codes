# Lab 06: Sensor Fusion (PIR + Ultrasonic)

## 🎯 Objective
Combine multiple sensors for decision-making.

## 🧠 Concepts Covered
- Multi-sensor input
- Logical conditions

## 🔧 Components Required
- PIR Sensor
- Ultrasonic Sensor
- LED

## 🔌 Pin Configuration
- PIR → Pin 7
- TRIG → Pin 9
- ECHO → Pin 10
- LED → Pin 11

## 📜 Description
LED turns ON only when motion is detected AND object is close.

## ▶️ How to Run
Upload code and observe behavior.

## 📈 Expected Learning Outcome
Students learn sensor fusion and decision systems.
